# Luvo Mobile

React Native app built on **Expo (SDK 56)** with Continuous Native Generation: `ios/` and `android/` are generated by `expo prebuild` and are git-ignored. Native config lives in `app.config.ts`. The app needs a development build (it uses Firebase, Mapbox and VisionCamera), so Expo Go is not supported.

## Setup

```sh
yarn install
cp .env.example .env   # fill in EXPO_PUBLIC_* values
```

## Run

```sh
yarn android      # expo run:android (prebuilds + builds the dev client)
yarn ios          # expo run:ios
yarn start        # Metro for an already-installed dev client
yarn prebuild     # regenerate native projects from scratch
```

Re-run `yarn prebuild` after changing `app.config.ts` plugins or native dependencies.

## Config

Runtime values come from `.env` as `EXPO_PUBLIC_*` variables and are read through `src/config/env.ts`.
Firebase files (`google-services.json`, `GoogleService-Info.plist`) live in the repo root and are wired in `app.config.ts`.

## Quality

```sh
yarn lint && yarn typecheck && yarn test
```
